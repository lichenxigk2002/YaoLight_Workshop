## 问题定位
- 你说的“图片展示方式”对应 AI 节点里把模型选择切到“图片（cards）”模式后，会用弹窗组件 [AIModelConfigPopup.tsx](file:///e:/Project/Graduation%20project/Low_code_Frontend/src/components/WorkflowEditor/configs/AIModelConfigPopup.tsx) 来配置参数。
- 弹窗里“流式输出 / 深度思考”等开关目前是这样写的：外层一个 `Form.Item name="stream" noStyle`，里面又放了 `SwitchPart name="stream"`，而 `SwitchPart` 自己内部也会再创建一个 `Form.Item name="stream"`（同名字段重复注册）。这会导致：界面看起来切换了，但表单真正保存时读取到的还是外层那个没更新的值，于是“点保存没保存到”。
  - 位置示例：[AIModelConfigPopup.tsx#L206-L235](file:///e:/Project/Graduation%20project/Low_code_Frontend/src/components/WorkflowEditor/configs/AIModelConfigPopup.tsx#L206-L235)
  - `SwitchPart` 内部包含 `Form.Item`：[SwitchPart.tsx](file:///e:/Project/Graduation%20project/Low_code_Frontend/src/components/WorkflowEditor/providers/parts/SwitchPart.tsx)

## 修复思路
- 在弹窗这种“行内布局（noStyle）+ 右侧控件”的场景，不能再用 `SwitchPart`（因为它自带 `Form.Item`）。
- 改为只保留一层 `Form.Item`，并在其中直接渲染不带 `Form.Item` 的控件：`SegmentedSwitch`。

## 具体改动
1. 修改 [AIModelConfigPopup.tsx](file:///e:/Project/Graduation%20project/Low_code_Frontend/src/components/WorkflowEditor/configs/AIModelConfigPopup.tsx)
   - 把 `import { SwitchPart } ...` 改为 `import { SegmentedSwitch } ...`。
   - 将以下两处：
     - `stream`：`<Form.Item name="stream" ...><SwitchPart name="stream" /></Form.Item>`
     - `thinking / enable_thinking`：`<Form.Item name=...><SwitchPart name=... /></Form.Item>`
     替换为：
     - `<Form.Item name="stream" initialValue={false} noStyle><SegmentedSwitch /></Form.Item>`
     - `<Form.Item name={...} initialValue={false} noStyle><SegmentedSwitch /></Form.Item>`
   - 这样每个字段只注册一次，点击切换会真实更新到 Form 的值，保存就会写进节点 config。
