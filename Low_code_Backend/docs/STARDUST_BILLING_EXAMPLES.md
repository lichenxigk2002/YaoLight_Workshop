## 计费基准：DeepSeek

**DeepSeek Chat 基准价格（USD）**：
- 输入Token（缓存未命中）：**$0.28 / 1M tokens**

## 计算逻辑说明

1. **基准**：DeepSeek作为1.0x基准
2. **倍数计算**：其他模型价格 / DeepSeek价格 = 倍数
3. **等效星尘**：实际Token数 × 倍数 = 等效星尘数
4. **货币转换**：CNY按0.14汇率转换为USD后计算
5. **分段计费**：根据上下文长度选择对应的价格段

## 注意事项

1. **汇率**：当前使用固定汇率 1 CNY = 0.14 USD，实际汇率可能波动
2. **缓存机制**：DeepSeek有缓存机制，缓存命中时输入倍数仅为0.1x
3. **分段计费**：qwen3-max和GLM系列根据上下文长度不同，倍数差异很大
4. **限时免费**：GLM系列有30-50天的限时免费期，价格约为标准价的1/5
