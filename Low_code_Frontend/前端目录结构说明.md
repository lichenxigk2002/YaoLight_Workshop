# 前端目录结构说明

## 📁 目录结构

```
Low_code_Frontend/src/
├── api/                    # API接口定义
│   ├── workflow.ts         # 工作流相关API
│   └── index.ts            # 统一导出
│
├── assets/                 # 静态资源
│   ├── images/            # 图片
│   ├── icons/             # 图标
│   └── fonts/             # 字体
│
├── components/             # 组件
│   └── WorkflowEditor/    # 工作流编辑器组件
│
├── data/                   # 数据相关
│   ├── mock.ts            # Mock数据
│   └── index.ts           # 统一导出
│
├── hooks/                  # 自定义Hooks
│   ├── useWorkflow.ts     # 工作流相关Hook
│   └── index.ts           # 统一导出
│
├── http/                   # HTTP请求配置
│   └── index.ts           # Axios实例和拦截器
│
├── pages/                  # 页面组件
│   └── auth/              # 认证相关页面
│
├── redux/                  # 状态管理（使用Zustand）
│   ├── auth.ts            # 认证状态
│   └── index.ts           # 统一导出
│
├── routes/                 # 路由配置
│   └── index.tsx          # 路由定义
│
├── test/                   # 测试文件
│
├── types/                  # TypeScript类型定义
│   └── index.ts           # 通用类型
│
├── utils/                  # 工具函数
│   └── index.ts           # 工具函数集合
│
├── App.tsx                 # 根组件
├── main.tsx               # 入口文件
└── index.css              # 全局样式
```

## 📝 目录说明

### api/
API接口定义，按业务模块划分
- `workflow.ts` - 工作流相关API
- 后续可添加：`user.ts`, `auth.ts` 等

### assets/
静态资源文件
- `images/` - 图片资源
- `icons/` - 图标文件
- `fonts/` - 字体文件

### components/
可复用组件
- `WorkflowEditor/` - 工作流编辑器组件

### data/
数据相关
- `mock.ts` - Mock数据（开发测试用）

### hooks/
自定义React Hooks
- `useWorkflow.ts` - 工作流相关Hook

### http/
HTTP请求配置
- `index.ts` - Axios实例、拦截器配置

### pages/
页面组件
- `auth/` - 登录、注册等认证页面

### redux/
状态管理（使用Zustand）
- `auth.ts` - 认证状态管理
- 后续可添加：`workflow.ts`, `user.ts` 等

### routes/
路由配置
- `index.tsx` - 路由定义

### test/
测试文件
- 单元测试、集成测试等

### types/
TypeScript类型定义
- `index.ts` - 通用类型定义

### utils/
工具函数
- `index.ts` - 通用工具函数（防抖、节流、格式化等）

## 🔄 迁移说明

### 已迁移的文件
- ✅ `services/api.ts` → `http/index.ts`
- ✅ `store/auth.ts` → `redux/auth.ts`
- ✅ 已删除空的 `services/` 和 `store/` 目录

### 已更新的导入路径
- ✅ 组件中引用 `services/api` 的地方已改为 `http`
- ✅ 组件中引用 `store/auth` 的地方已改为 `redux/auth`
- ✅ `main.tsx` 已更新为使用路由系统

## 📌 使用建议

1. **API调用**：统一使用 `api/` 目录下的接口
2. **状态管理**：使用 `redux/` 目录下的Zustand store
3. **HTTP请求**：通过 `http/index.ts` 导出的实例
4. **工具函数**：从 `utils/` 导入
5. **类型定义**：从 `types/` 导入
