# 瑶光星历史归档文档

本目录存放**旧版方案、阶段性实现总结、历史任务清单与检查清单**。

这些文档用于：

- 回溯历史设计
- 查找旧实现背景
- 评估兼容性与可复用模块

这些文档**不作为当前产品方案的主依据**。

## 使用规则

1. 当前需求讨论时，默认不要先读本目录。
2. 只有在需要确认历史约束、查旧实现细节、复用已有模块时，再按需打开。
3. 如果本目录文档与 `../01-ALKaid-Technical-Architecture.md` 冲突，以当前技术架构文档为准。
