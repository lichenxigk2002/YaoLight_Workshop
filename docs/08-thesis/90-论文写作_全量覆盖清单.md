## 1. 论文建议题目

**基于 Go 与 React 的低代码智能工作流平台“瑶光工坊”的设计与实现**

可选副标题：

- 面向可视化编排、AI 生成与网络数据采集的一体化平台设计
- 融合 Agentic 工作流生成与并发执行引擎的低代码系统研究

## 2. 项目总体定位

“瑶光工坊”不是单一的工作流编辑器，而是一个由三部分组成的完整平台：

1. 用户端前台：面向普通用户，负责项目管理、工作流编辑、任务执行、资产管理、开放 API、支付充值和个人设置。
2. 后端服务：基于 Go + Gin + GORM + PostgreSQL + Redis，提供认证、工作流执行、AI 适配、爬虫、任务调度、开放 API、通知、计费和 RBAC 等能力。
3. 管理后台：面向管理员，负责用户、权限、模板、节点类型、知识库、爬虫规则、AI 模型、任务、账务、通知和操作日志管理。

## 10. 当前最适合写成“创新点”的内容

建议优先写这 5 个，最稳：

1. **面向低代码工作流的 Agentic 生成闭环**：不是单轮生成 JSON，而是“能力感知 + 工具调用 + 试跑校验 + 修复 + 人工确认”的闭环。
2. **能力说明自动抽取机制**：通过 `config_extractor` 从节点执行源码抽取配置字段，减少文档与代码不一致问题。
3. **并发工作流执行引擎**：支持 DAG 依赖解析、节点级并发、节点记录与任务日志联动。
4. **Artifact 统一输出机制**：把输出结果统一建模为工件，打通下载、邮件发送和开放 API 获取。
5. **平台级治理能力嵌入低代码系统**：RBAC、通知、账务、操作日志不是外挂，而是内建到平台架构中。
